## 1. Problem Statement

Managing student academic information manually can make it difficult to maintain student details, course marks, attendance records, and academic performance in an organized manner.

The **Student Academic Management System** is developed as a terminal-based Java application to provide a simple way to manage these academic records.

The system allows users to:

- Add, search, update, display, and delete student information  
- Manage course marks and attendance  
- Calculate academic performance  
- Generate reports  
- Save student records to text files  

---

## 2. Project Scope

The scope of the project includes:

- Managing student information  
- Managing course marks  
- Calculating total and average marks  
- Calculating overall grades  
- Managing attendance information  
- Calculating attendance percentage  
- Generating academic performance reports  
- Saving student records to text files  
- Reading saved student records  
- Validating user input  
- Demonstrating Java programming and Object-Oriented Programming concepts  

The current system is designed as a **command-line application** and does not include a graphical user interface or database.

### Java Concept Demonstration

The project demonstrates the following Java concepts:

| Concept                | Usage in Project                          |
|------------------------|-------------------------------------------|
| Classes and Objects    | `Student`, `Course`, `Attendance`, etc.   |
| Constructors           | Object initialization in domain classes   |
| Static Methods         | Grade calculation / report helpers        |
| Method Overloading     | `addCourse()` and related methods         |
| Inheritance            | `Student extends Person`                  |
| Method Overriding      | `displayInfo()` in `Student`              |
| `super` Keyword        | Constructor and method delegation         |
| Runtime Polymorphism   | `Person` reference to `Student` object    |
| Abstract Class         | `Person`                                  |
| Interface              | `Printable`                               |
| Multithreading         | `ReportThread extends Thread`             |
| Loops                  | Processing and factorial calculation      |
| Exception Handling     | Input validation and file operations      |
| Java I/O Streams       | Writing and reading student record files  |
